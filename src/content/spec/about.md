## 关于我

我是一名嵌入式软件工程师，目前主要负责基于主流 Linux 系统的物联网云平台开发及数据采集驱动开发。

工作方向包括：

- 对接各类物联网平台（如用户大数据平台、智慧城市、智慧工厂等）
- 平台接入认证、数据传输、配置下发、数据清洗与加工上传等功能的开发
- 采集与处理多种工业设备数据，支持 `ModbusTCP`、`ModbusRTU` 等常用工业通讯协议

技术栈方面：

- 主力语言为 `Go`，辅助语言包括 `Python`、`C`、`C++` 及 `Shell` 脚本
- 主要基于 `Ubuntu`、`CentOS` 和 `Windows` 平台进行应用层开发
- 有 32 位 `armv7l` 嵌入式平台的开发经验，熟悉 Go 和 C 语言的交叉编译、调试与发布流程，熟悉 `Makefile` 的工作原理
